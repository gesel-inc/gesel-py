gesel.consolidate_block_size(block_size=None)[source]¶

Get or set the block size for consolidating HTTP range requests.

Each file is split up into blocks of size approximately equal to block_size. When performing a range request, all ranges in the same block will be retrieved. This consolidates near-adjacent ranges into a single request, reducing the number of requests at the cost of increasing the size of each request.

All ranges associated with a block will be cached in memory, even those that were not directly requested. Subsequent function calls can then quickly retrieve ranges from this cache instead of making a new HTTP request. Downloading and caching the entire block also ensures that the same bytes will never be requested from the server twice in the same session.

Setting the block size to a value of 1 indicates that no consolidation is to be performed, i.e., each range is requested as-is.

Parameters:

block_size (int | None) – Block size in bytes. Larger sizes reduce the number of requests at the cost of increasing the size of each request.

Return type:

int

Returns:

If block_size = None, the current block size is returned.

If block_size is provided, it is used to set the block size, and the previous value is returned.

Examples

>>> import gesel
>>> gesel.consolidate_block_size()
>>> old = gesel.consolidate_block_size(500)
>>> gesel.consolidate_block_size()
>>> gesel.consolidate_block_size(old)

gesel.flush_memory_cache(config=None)[source]¶

Flush the in-memory cache for Gesel data structures in the current Python session. By default, Gesel functions caches the data structures in the current session to avoid unnecessary requests to the filesystem and remote server. On rare occasion, these cached data structures may be out of date when the Gesel database files change. In such cases, the cache can be flushed to ensure that the various Gesel functions operate on the latest version of the database.

Parameters:

The in-memory cache in config is cleared.

gesel.new_config(fetch_gene=None, fetch_gene_kwargs={}, fetch_file=None, fetch_file_kwargs={}, fetch_ranges=None, fetch_ranges_kwargs={}, consolidate_block_size=None)[source]¶

Create a new configuration object to specify how the Gesel database should be queried. This can be passed to each Gesel function to alter its behavior in a consistent manner. For example, we could point to a different Gesel database from the default, or we can override fetch_file to retrieve database files from a shared filesystem instead of performing a HTTP request.

The configuration list also contains a cache of data structures that can be populated by Gesel functions. This avoids unnecessary fetch requests upon repeated calls to the same function. If the cache becomes stale or too large, it can be cleared by calling flush_memory_cache().

If no configuration list is supplied to Gesel functions, the default configuration is used. The default is created by calling new_config() without any arguments.

Parameters:

  • fetch_gene (Callable | None) – Function that accepts the name of the file in the Gesel gene descriptions and returns an absolute path to the file. If None, it defaults to download_gene_file().

  • fetch_gene_kwargs (dict) – Dictionary of name:value pairs containing extra arguments to pass to fetch_gene.

  • fetch_file (Callable | None) – Function that accepts the name of the file in the Gesel database and returns an absolute path to the file. If None, it defaults to download_database_file().

  • fetch_file_kwargs (dict) – Dictionary of name:value pairs containing extra arguments to pass to fetch_file.

  • fetch_ranges (Callable | None) –

    Function that accepts three arguments:

    • name, the name of a Gesel database file.

    • start, a list of integers containing the zero-indexed closed start of each byte range to extract from the file. This may be of zero length.

    • end, a list of integers containing the zero-indexed open end of each byte range to extract from the file. This should have the same length as start such that the i-th byte range is defined as [start[i], end[i]). The set of byte ranges should be non-empty, non-overlapping, and sorted by increasing start/end position.

    It should return a list containing tuples of:

    1. A byte string representing the contents of a “retrieved” byte range.

    2. An integer containing the zero-indexed closed start of the retrieved range.

    3. An integer containing the zero-indexed open end of the retrieved range.

    All retrieved byte ranges are non-empty but may be overlapping and in any order. Each “requested” byte range (i.e., defined by start and end) will be enclosed within at least one retrieved byte range. Note that the retrieved byte ranges may not have a 1-to-1 mapping to the requested byte ranges, e.g., if the server decides that adjacent requested ranges can be merged into a single output range.

    If None, it defaults to download_database_ranges().

  • fetch_ranges_kwargs (dict) – Dictionary of name:value pairs containing extra arguments to pass to fetch_ranges.

  • consolidate_block_size (int | None) – Block size for consolidated requests. If None, it defaults to consolidate_block_size().

Return type:

dict

Returns:

Dictionary of Gesel configuration settings.

Examples

>>> import gesel
>>> gesel.new_config()

Each of its inner lists set_membership[i][j] corresponds to the j-th gene set in the i-th collection. Each inner list contains the identities of the constituent genes in that set. Each gene is identified as a row index into the BiocFrame returned by fetch_all_genes(). All gene indices should be positive and no greater than num_genes. Inner lists may be unsorted and contain duplicate entries - sorting and deduplication will be performed internally.

  • num_genes (int) – Total number of genes available for this species.

  • path (str) – Path to a directory in which to create the database files.

  • validate (bool) – Whether to run validate_database_files() on the newly created files.

Return type:

None

Returns:

Several files are produced inside path with the species_ prefix. None is returned.

Examples

>>> import biocframe
>>> collections = biocframe.BiocFrame({
...     "title": ["FOO", "BAR"],
...     "description": ["I am a foo", "I am a bar"],
...     "maintainer": ["Aaron", "Aaron"],
...     "source": ["https://foo", "https://bar"]
... })
>>>
>>> set_info = [
...     biocframe.BiocFrame({
...         "name": ["FOO_" + str(i) for i in range(20)],
...         "description": ["this is FOO " + str(i) for i in range(20)]
...     }),
...     biocframe.BiocFrame({
...         "name": ["BAR_" + str(i) for i in range(50)],
...         "description": ["this is BAR " + str(i) for i in range(50)]
...     })
... ]
>>>
>>> num_genes = 10000
>>> import random
>>> set_membership = [
...     [random.sample(range(num_genes), random.sample(range(500), 1)[0]) for i in range(20)],
...     [random.sample(range(num_genes), random.sample(range(200), 1)[0]) for i in range(50)]
... ]
>>>
>>> import tempfile
>>> output = tempfile.mkdtemp()
>>> import gesel
>>> gesel.prepare_database_files(
...     "1234",
...     collections,
...     set_info,
...     set_membership,
...     num_genes,
...     output
... )
>>>
>>> import os
>>> config = gesel.new_config(fetch_file = lambda x : os.path.join(output, x))
>>> print(gesel.fetch_all_sets("1234", config = config))

gesel.query_sets(species, genes=None, text=None, types=None, counts_only=True, config=None)[source]¶

Query gene sets based on overlaps with genes of interest or matches to keyboards in their names/descriptions. This is a user-friendly wrapper for quick and convenient searching of the Gesel database; developers may prefer to use lower-level functions for more customization and flexibility.

Parameters:

  • species (str) – NCBI taxonomy ID of the species of interest.

  • genes (list | None) – List of gene identifiers of any supported type. These are typically Ensembl/Entrez identifiers or gene symbols. If provided, this function will search for gene sets that overlap any of the supplied genes.

  • text (str | None) – One or more keywords with which to search on, see the query argument in search_set_text(). If provided, this function will search for gene sets that contain the (tokenized) keywords in their names or descriptions.

  • types (list | None) – Types of gene identifiers to consider for genes. This should contain one or more of any type listed in fetch_gene_types(). If None, it defaults to all available types in fetch_gene_types().

  • counts_only (bool) – Whether to return a list of the overlapping genes in each set. Only used if genes is provided.

  • config (dict | None) – Configuration object, typically created by new_config(). If None, the default configuration is used.

Return type:

BiocFrame

Returns:

A BiocFrame containing one row per set that matches the query conditions. This contains the following columns:

  • name, string containing the name of the gene set.

  • description, string containing a description of the gene set.

  • size, integer specifying the number of genes in this gene set.

  • collection, the name of the collection that contains this gene set.

  • set, integer specifying the Gesel set index that can be used in other functions like fetch_genes_for_some_sets().

If genes is provided, the data frame will additionally contain:

  • count, integer containing the number of overlaps between the genes in the set and those in genes.

  • which, a nested list where each entry is a character vector containing the genes in genes that are present in each set. Only reported if counts_only = False.

  • pvalue, a numeric column containing the hypergeometric p-value for overrepresentation of genes in each set. Rows will be sorted by this column if it is present.

Examples

>>> import gesel
>>> out = gesel.query_sets(
>>>     species = "9606",
>>>     genes = ["tead1", "tead2", "tead3", "tead4"],
>>>     text = "transcription"
>>> )
>>> print(out)
>>>
>>> out2 = gesel.query_sets(
>>>     species = "9606",
>>>     genes = ["SNAP25", "neurod4", "neurod6"],
>>>     text = "neuro*",
>>>     counts_only = False
>>> )
>>> print(out2)

gesel.search_overlapping_sets(species, genes, counts_only=True, test_enrichment=True, config=None)[source]¶

Find all sets overlapping any gene in a user-supplied list, and return the number of overlaps per set.

Parameters:

  • species (str) – NCBI taxonomy ID of the species of interest.

  • genes (list) – List of integers containing gene indices. Each gene index refers to a row of the data frame returned by fetch_all_genes().

  • counts_only (bool) – Whether to only report the number of overlapping genes for each set.

  • test_enrichment (bool) – Whether to compute a hypergeometric p-value for enrichment of genes in each set.

  • config (dict | None) – Configuration object, typically created by new_config(). If None, the default configuration is used.

Return type:

BiocFrame

Returns:

A BiocFrame where each row represents a set. It contains the following columns:

  • set, the identity of the set corresponding to each row. This set index refers to a row of the data frame returned by fetch_all_sets().

  • counts, the number of overlaps between the genes in the set and those in genes.

  • which, if counts_only = False. This contains the entries of genes that overlap with those in the set.

  • size, if test_enrichment = True. This contains the size of the set.

  • pvalue, if test_enrichment = True. This contains the hypergeometric p-value for overrepresentation of genes in the set.

The row order is arbitrary.

If test_enrichment = True, the BiocFrame will also contain a present integer in its metadata. This is the number of genes in genes that are present in at least one set in the Gesel database for species. The value of present is intended for use as the number of draws when performing a hypergeomtric test for gene set enrichment, instead of len(genes). It ensures that genes outside of the Gesel universe are ignored, e.g., due to user error, different genome versions. Otherwise, unknown genes would inappropriately increase the number of draws and inflate the enrichment p-value.

Examples

>>> # Pretend we're interested in the first 10 genes.
>>> genes_of_interest = range(10)
>>>
>>> import gesel
>>> overlaps = gesel.search_overlapping_sets("9606", genes_of_interest)
>>> print(overlaps)
>>>
>>> # More details on the overlapping sets.
>>> all_sets = gesel.fetch_all_sets("9606")
>>> print(all_sets[overlaps["set"],:])
